# Excel Sales Dashboard Project

## Overview

This project is an interactive **Sales Performance Dashboard** created using Microsoft Excel.

The purpose of this project is to analyze sales data, track key business metrics, and visualize important sales trends using Excel dashboards, Pivot Tables, and Pivot Charts.

## Project Objectives

* Organize and analyze sales transaction data
* Calculate important business KPIs
* Identify top-performing products and regions
* Analyze monthly revenue trends
* Create an interactive dashboard for decision-making

## Tools & Skills Used

* Microsoft Excel
* Excel Tables
* Data Formatting
* Excel Formulas
* Pivot Tables
* Pivot Charts
* Dashboard Design
* Data Visualization

## Workbook Structure

### 1. Sales Data Sheet

Contains the main sales dataset with information such as:

* Order ID
* Date
* Product
* Region
* Quantity
* Sales Revenue

The data was formatted into an Excel Table for better management and analysis.

### 2. KPI Metrics Dashboard

Created KPI cards to display:

* Total Revenue
* Average Revenue
* Total Orders
* Highest Revenue Product
* Highest Revenue Region
* Highest Revenue Month

### 3. Pivot Table Analysis

Created Pivot Tables for:

* Monthly Revenue Analysis
* Product Revenue Analysis
* Regional Revenue Analysis

### 4. Dashboard Visualizations

Created interactive charts including:

* Monthly Revenue Trend Chart
* Revenue Distribution by Product
* Revenue Analysis by Region

## Key Insights Generated

* Analyzed monthly revenue performance
* Identified the highest performing product
* Compared sales performance across regions
* Created a business-focused sales reporting dashboard

## Project Outcome

This project demonstrates practical Excel skills used in entry-level Data Analyst roles, including data organization, analysis, visualization, and dashboard creation.
